so this was an experiment to make a modular mapper which is faster than the original (terrible) software for the loupedeck ct. this is kinda hacky, but it works.

config syntax (will make a web generator in the future)

name - completely irrelevant currently, potential for switching between configs on a bind
keycolor - if you want the display keys to be colored, you set them here, both hex and csds colors work
bindcommand - if the bindtype for that key is shell, here you set what is ran inside the shell
bindtype - currently only shell, probably will make a keybind one, macro one, switching workspaces, idk
